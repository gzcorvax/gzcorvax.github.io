IDEA安装TRAE插件进行AI编程

发表于2026-03-29|更新于2026-07-22|企业动态
|浏览量:

在 IntelliJ IDEA 中安装 Trae 插件很简单，直接在插件市场搜索安装即可。

一、📝 安装步骤

打开插件市场：在 IDEA 中，进入 File -> Settings (Windows/Linux) 或 IntelliJ IDEA -> Preferences (macOS)，然后选择 Plugins。也可以使用快捷键 Ctrl+Alt+S (Windows/Linux) 或 Cmd+, (macOS) 快速打开设置。
搜索并安装：在插件市场的 Marketplace 标签页中，搜索 Trae AI。找到名为 TRAE AI: Coding Assistant 的插件，点击 Install 按钮即可。
重启 IDEA：安装完成后，根据提示重启 IDEA 使插件生效。

注意：
插件全称是 TRAE AI: Coding Assistant，支持 IntelliJ IDEA 2022.3 及以上版本。
如果在市场搜不到，可添加官方插件仓库 https://plugins.trae.ai/update-center.json 后再试。
该插件曾用名是 MarsCode，是字节跳动出品。

二、🚀 首次使用配置

重启后，还需要进行登录和基本设置：
登录/注册：点击 IDEA 右侧边栏的 Trae AI 图标，按提示使用手机号、微信或 GitHub 等账号登录激活。
基础设置：可在 File -> Settings -> Tools -> Trae AI 中进行个性化配置。推荐设置如下：
默认模型：Doubao-Seed-2.0-Code Beta（代码专用旗舰模型）
代码补全开关：开启
补全触发延迟：300ms（最佳手感区间）

三、🎯 如何使用

成功安装后，可以通过以下几种方式使用 Trae AI：
右键菜单：在编辑器中选中代码，右键点击，在 Trae AI 子菜单中选择功能。
快捷键：在 Settings -> Keymap 中搜索 Trae AI 自定义快捷键。
命令面板：使用 Ctrl+Shift+A 打开命令面板，输入 Trae AI: 选择功能。
它的核心功能包括代码生成、解释、优化、单元测试生成和智能修复等。

四、⚠️ 常见问题

安装后无反应？：确保已按提示重启 IDEA。
国内市场搜不到？：尝试添加官方插件仓库。
登录失败？：检查网络，确保能访问浏览器完成授权流程。
代码补全不工作？：检查设置中“代码补全开关”是否开启。
